# Codex·ChatGPT 사설 패치 통합 릴리즈 노트

2026-10-27 기준 · 개인 운영 환경의 현재 적용본: **R24 v2**

Windows Codex 데스크톱 앱과 내부 app-server에 만든 비공식 사설 패치의 이력입니다. 데스크톱 실행 파일 이름이 `ChatGPT.exe`여서 제목에 함께 표기했으며, ChatGPT 공식 제품의 릴리즈 이력이 아닙니다.

**이 문서는 변경 이력의 공개본입니다. 이 저장소에서 제공하는 소스는 r22이며, 아래 R23·R24 및 후속 후보 전체의 소스나 설치 가능한 데스크톱 패키지가 공개됐다는 뜻이 아닙니다.** 바이너리·ASAR·비공개 데스크톱 UI 자산·개인 로그·인증 자료는 포함하지 않습니다. 저장소의 공개 소스 범위는 [수정 고지](../../MODIFICATIONS.md), 기존 시험의 범위와 한계는 [테스트 문서](../TESTING.md)를 따릅니다.

## 변경 흐름

Windows 소켓 상속 수정 → 접근 거부 반복 조회 억제 → RPC 수명·취소·중복 공유 교정 → 지연·메모리 진단 보강 → Windows MCP 파이프와 config 읽기 수정 → 입력/RPC 연결·비동기 로그 → 플러그인 재로딩·세션 Fast 설정 → capacity 자동 재개·계정 변경 취소·캐시 진단 순으로 진행했습니다.

아래는 보존된 당시 변경·시험·적용 기록을 요약한 것입니다. 날짜는 KST이며 ‘과거 적용’은 당시 개인 환경의 실행 확인을 뜻합니다. 일반 배포나 현재 모든 사용자의 적용 상태를 뜻하지 않습니다. 소스 보존본의 `r01/r02`, 시험 후보 `v2/v3`를 별도 앱 릴리즈로 세지 않았습니다.

## 현재 기능과 사용 시 주의점

- **권한 거부:** 거부를 성공으로 바꾸지 않습니다. 반복 조회를 줄이되 TTL·명시적 재조회·계정 및 접근 상태 변화 시 원래 권한 검사로 다시 확인합니다.
- **플러그인 갱신:** R23 계열의 `Reload plugins` 경로는 skills 갱신 결과와 native 재연결 예약 응답을 확인하도록 구성했습니다. `queued`는 ready 완료가 아닙니다. 실제 서비스 전체의 무재시작 재연결 성공은 미확인입니다.
- **Fast 설정:** 현재 세션·초안의 선택과 General Settings의 전역 기본값을 구분합니다. host·account·manager가 바뀌면 오래된 handler의 쓰기를 거부하도록 구성했습니다.
- **진단:** 입력·RPC·DOM/frame·프로세스·보유 컬렉션·캐시 자료는 서로 다른 측정입니다. 표본 없음·수집 실패·꺼진 계측을 지연 0이나 메모리 0으로 해석하지 않습니다.

현재 적용본의 공식 앱 기반은 **26.1021.3705.0**, 포함 native/app-server는 **0.164.0-alpha.11.1**입니다. 별도 npm CLI **0.164.0**과 구분합니다. 패치 전용 실행기를 통한 개인 환경의 실행 확인이며, 이 저장소는 데스크톱 설치 지침이나 설치 파일을 제공하지 않습니다.

## 후속 후보 — 아직 운영 미적용

### 로컬 기록과 Python 전송 분리

앱은 먼저 로컬 디스크에 durable 기록을 남기고 별도 Python 작업자 하나가 전송하도록 변경합니다. 원격 드라이브에서는 날짜 폴더 아래 20자리 시각의 새 완성 파일을 만들고, 기존 완성 파일에는 append하지 않습니다. 재시도 시 record UUID는 유지하고 attempt UUID는 새로 부여합니다.

경로 대소문자 alias, frame/RPC 계측 연결, collector의 metadata 해석을 수정했습니다. 다른 record UUID로 같은 논리 이벤트가 다시 전달됐을 때 정상 중복과 실제 내용 충돌을 구분하도록 추가 교정했습니다.

초기 동결본은 **14개 명령 종료 코드 0**의 격리 시험 기록이 있습니다. 후속 고정 패키지는 앱 overlay 8개·모니터 파일 24개의 해시 일치, worker 41초 시험, SQLite 다중 slice 및 이벤트 중복·충돌 구분을 확인했습니다. 독립 감사의 PASS는 **고정 후보 제작·격리 기능 검증·배포 전 소스 감사 범위**입니다. 운영 파일·설정·예약 작업·바로가기는 아직 바꾸지 않았습니다.

실제 앱 기동·사용자 입력·장기 부하·원격 드라이브 미마운트·전원 차단 조건은 미검증입니다. 로컬 spool 보존 상한이 없어 저장 공간을 소진할 수 있습니다. 이 후보의 시험·감사 통과는 실제 적용이나 원래 문제 해결의 PASS가 아닙니다.

### 모니터 실행 시간 제한 정리

50초·40초 강제 종료를 제거하고 submit/latency 작업의 실행 주체를 하나로 정리하는 후보입니다. 운영 설정은 여전히 **1분 주기(PT1M), 중복 실행 방지(IgnoreNew), 5분 실행 제한(PT5M)**입니다. 시간 제한 제거의 운영 적용은 아직 끝나지 않았습니다.

### 이월된 작업

세션별 context 창 UI/native, 실행 중 manual compact의 다음 turn 예약, 최근 10 turn 최적화, native cache producer r02는 최종 검증·빌드가 끝나지 않아 이번 빠른 릴리즈에 포함되지 않았습니다.

## 검증 결과의 해석과 미확인 사항

확인된 소켓 상속·중복 요청·파이프 pool 점유·중복 config load·계측 선택/축소 결함에는 각각 재현·수정 근거가 있습니다. 그러나 이를 합쳐 장시간 타이핑·채팅 전환 지연, 모든 연결·프로세스 누적, 메모리 증가·충돌, 캐시 급락을 완전히 해결했다고 결론 내리지는 않습니다. R8b/R9의 자체 회귀와 이후 교정·롤백 이력도 위 표에 남겼습니다.

R17의 **NTFS 압축**은 실제 과거 파일의 할당 공간 절감입니다. R23의 **gzip 사본 생성**은 별도 구현으로, 원본을 보존하므로 원본 공간 회수를 완료한 기능으로 세지 않습니다. 어느 경우도 모든 장애에서 무손실을 보장하지 않습니다.

수정 사본의 내장 ASAR 해시를 갱신한 실행 파일은 공급자 Authenticode 서명 유효성을 유지하지 못합니다. 공식 원본은 별도로 보존했습니다. 이는 서명·인증·권한 검사를 제거한 변경이라는 뜻이 아닙니다.

- R1·R2·R6·R7b·R8b·R9·R10~R24를 확인 가능한 범위에서 기록했습니다. R3~R5의 독립된 릴리즈 근거는 부족해 번호를 채우지 않았습니다.
- R7c는 r7b 앱을 실행한 launcher 개정입니다. R12·R21의 독립된 운영 배포 완료 근거는 부족하며, 후보 시험과 후속 버전 이식을 구분합니다.
- 당시 빌드·시험·개인 운영 적용 기록을 요약했습니다. 이 문서를 작성하면서 제품 시험이나 모든 과거 실행물의 존재·해시를 다시 전수 확인하지 않았습니다.
- 개인 경로·프로세스 식별자·내부 영수증 및 운영 로그 위치는 공개본에서 제외했습니다. 공개 저장소에서 재현 가능한 r22 시험 범위는 [테스트 문서](../TESTING.md)를 참고하십시오. 비공개 단계의 원시 기록을 공개한 문서가 아닙니다.
