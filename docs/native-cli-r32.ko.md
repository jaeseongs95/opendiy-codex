# R32 캐시 관측 후속 후보

R31 동결본을 바꾸지 않고 준비한 후속 소스 패치입니다. 배포·설치한 버전이 아니며 실행 시험과 독립 검토는 아직 완료하지 않았습니다.

| 구성 | 기준 | 상태 |
| --- | --- | --- |
| R31 기반 | 공식 0.166.0, `1cd3bbff28286f081ee3bda32487c0313430ad2c` | 기존 최종 빌드 후보 보존 |
| R32 소스 후보 | `2f42356a343c663ed2c03efede9a842b84d57dab` | 구현·회귀시험 코드 준비 |
| OpenDIY Desktop 대응판 | 담당자와 버전 조합 조율 중 | 실제 공동시험 전 |

## 확인한 결함과 교정

캐시 관측 생산자는 `codex_api::prompt_cache` 대상으로 `DEBUG` 이벤트를 내보내지만, 기존 CLI 배치 수집기는 `INFO`까지만 받습니다. 기존 필드 목록에는 `cached_tokens`, 캐시 상태 구분과 반환 서비스 등급도 빠져 있습니다. 따라서 이 배치 경로만으로 캐시 관측을 보존할 수 없습니다. 이 소스상 결함이 현재 운영 로그 누락의 원인 전부라는 뜻은 아닙니다.

후속 패치는 `cli-logging.toml`의 `prompt_cache = true`로 해당 구조화 이벤트만 선택해 받습니다. 기본값은 꺼짐입니다. 일반 디버그 이벤트와 자유 형식 메시지는 받지 않고, 허용한 숫자·상태·길이 제한 식별자만 기록합니다. 누락 상태와 실제 0을 구분하며 기존 큐·버퍼·파일 게시 방식은 그대로 사용합니다.

대화 화면, 비대화 실행, 별도 앱 서버의 세 초기화 경로가 동일한 필터를 사용합니다. 통신 규약과 프롬프트 캐시 정책은 변경하지 않습니다. 이 설정은 후속 소스에서만 지원하며 R30·R31 설정에 미리 추가하면 안 됩니다.

## 검증 상태

- 형식 검사, 변경분 공백 검사, 공개 R31 소스에 대한 패치 적용 가능성 검사: 통과.
- 회귀시험 코드: 선택 수집과 일반 디버그 차단, 누락과 0 구분, 비정상 라벨·음수·비밀 필드 제외.
- 회귀시험 실행·최종 컴파일·독립감사·Desktop 공동시험·캐시 적중률 개선: 미검증.

실제 제품 시험은 진행 중인 R31 빌드와 분리해 수행합니다. 최종 배포에서는 CLI와 별도 앱 서버의 버전·소스·실행 파일 해시를 함께 고정하고, [OpenDIY Desktop](https://github.com/jaeseongs95/opendiy-desktop) README와 검증 조합을 맞춥니다.

소스 변경분은 [R32 후속 패치](../patches/r32-cache-observation.patch)에 있습니다. 이 브랜치의 기본 소스 목록은 R31 기준을 유지하며, 패치는 기본 소스에 자동 적용되지 않습니다.
