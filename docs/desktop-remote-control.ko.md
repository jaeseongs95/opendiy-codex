# 데스크톱 세션별 원격 제어 격리

`codex app-server --remote-control-client-name <NAME>`은 같은 계정으로 실행한 서버의 원격 등록을 이름별로 나누는 선택 옵션입니다. 이름은 영문·숫자·`-_.`로 된 1~128자이며, 데몬 및 도구 하위 명령에는 적용할 수 없습니다. 옵션을 생략하면 기존 동작을 유지합니다.

이름별 저장 키와 원격 연결 설치 식별자를 함께 분리합니다. 기존 설치 식별자 파일을 덮어쓰지 않으며 다른 서버의 등록을 삭제하지 않습니다. OpenDIY Desktop은 자신이 소유한 서버마다 고유 이름을 전달합니다. 기존 CLI 실행 파일과 인증·설정을 자동으로 바꾸지 않습니다.

시험한 런타임 소스는 `64eddac48043abbb8defeb39fbcfd4b0301b7341`입니다. 원격 전송 시험 140개와 CLI 옵션 시험 32개가 통과했고, 독립 네임스페이스 시험과 실제 앱의 로그인 없는 상태조회도 통과했습니다. 이 공개 트리는 별도의 기존 예약 기능 변경도 포함하므로 전체 트리를 같은 실행 파일로 빌드했다고 주장하지 않습니다. 변경한 8개 파일의 본문은 수정 고지와 줄바꿈을 제외하면 시험한 소스와 같습니다. 파일 및 시험 로그 해시는 [검증 정보](desktop-remote-control-evidence.json)에 있습니다.

실제 계정 활성화·연결 코드 발급·휴대전화 종단 제어는 아직 시험하지 않았습니다. 실행 파일은 이 소스 갱신에 포함하지 않습니다.
