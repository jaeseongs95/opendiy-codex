# Native CLI R27

기반은 공식 Codex CLI 0.165.0입니다. R26의 수정과 기능을 유지하며 CLI 로그 수집, 대화별 컨텍스트 창 설정, 한국어 UI를 추가합니다. 기존 설치본과 전역 설정은 자동 변경하지 않습니다.

## 대화별 컨텍스트 창

- `/context`: 현재 대화에 저장된 값과 서버가 계산한 사용 가능 토큰을 조회합니다.
- `/context 120000`: 이후 턴에 적용할 창 크기를 지정합니다.
- `/context reset`: 이 대화의 덮어쓰기를 해제합니다. `default`도 같은 의미입니다.

실행 중인 턴은 시작할 때의 값을 유지합니다. 설정은 대화 기록에 저장되어 재개 후에도 유지됩니다. 전역 설정과 다른 대화는 바뀌지 않습니다. 모델 카탈로그 한도를 늘리는 기능은 아닙니다. 한도를 넘는 값, 0 이하, 사용 가능 토큰이 없는 값, 한도를 확인할 수 없는 모델은 서버에서 거부합니다. 예를 들어 headroom이 95%인 모델에서 120000을 지정하면 사용 가능 예산은 114000입니다.

## 한국어와 영어

시작 기본 언어는 한국어입니다. 영어로 실행하려면 PowerShell에서 다음과 같이 지정합니다.

```powershell
$env:CODEX_UI_LANGUAGE = 'en'
codex
```

`ko`로 한국어를 지정할 수 있습니다. 이 설정은 사용자 입력, 모델에 보내는 지침, 프로토콜 값, 슬래시 명령·단축키를 바꾸지 않습니다. 주요 도움말·승인·상태·설정·로그인·폴더 신뢰 안내를 번역합니다. 등록되지 않은 설명과 모델·서버가 반환하는 원문 등에는 영어가 남을 수 있습니다.

## 비동기 로그

사용자가 직접 `CODEX_HOME/cli-logging.toml`을 만들고 켠 경우에만 수집합니다. 파일이 없으면 꺼져 있습니다. 예시:

```toml
enabled = true
destination = 'G:\내 드라이브\앱로그\cli-r27'
flush_seconds = 60
sample_seconds = 5
max_batch_bytes = 16777216
rpc = true
events = true
process = true
```

`rpc`, `events`, `process`로 항목을 개별 설정합니다. `destination`을 생략하면 로컬 저장만 합니다. 주기는 1~3600초, 버퍼는 16KiB~64MiB 범위이며 잘못된 설정은 오류로 알립니다.

생산자는 디스크에 쓰지 않고 용량이 제한된 큐에 이벤트를 넣습니다. 별도 스레드가 메모리 버퍼를 로컬 `CODEX_HOME/log/cli-batches/YYYYMMDD`에 완결 파일로 저장합니다. 파일명은 `YYYYMMDDHHMMSS`와 소수 6자리, PID, UUID를 조합합니다. 각 완결 파일은 다시 열어 덧붙이지 않습니다.

별도 내보내기 스레드가 약 60초마다 완결 파일을 목적지의 날짜 폴더에 새 이름으로 복사하고 파일 핸들을 닫은 뒤 로컬 원본을 제거합니다. 이미 존재하는 목적지 파일을 덮어쓰지 않습니다. 목적지에 접근하지 못하면 로컬 원본을 보존해 다음 회차에 재시도합니다. 이 성공은 파일 시스템 복사 성공이며 Google Drive 클라우드 업로드 ACK를 뜻하지 않습니다. 앱 종료는 Drive I/O를 기다리지 않습니다.

기록 범위는 INFO 이상 Codex 이벤트 메타데이터, RPC span 시작·종료·경과시간, 허용된 요청/대화/턴 ID·숫자 필드, 프로세스 RSS 및 내부 진단 gauge입니다. 자유 형식 메시지·프롬프트·인증 헤더·임의 Debug 객체는 기록하지 않습니다. 기존 대화 저장과 인증 데이터는 변경하지 않습니다.

큐·배치가 가득 차면 생산자를 멈추지 않고 누락 수를 기록합니다. `batch_summary.collector`의 `dropped`, `local_failures`, `export_failures`, `exported`와 마지막 오류 종류/OS 코드를 확인할 수 있습니다. 비정상 종료 시 마지막 메모리 버퍼는 유실될 수 있습니다. 로컬 미전송 파일이 남으면 다음 실행에서 재시도합니다. 로그 누락을 정상 수치로 해석해서는 안 됩니다.

## 검증 범위

컨텍스트 설정은 실제 app-server/Core 경계에서 대화 격리·재개·리셋·실행 중 턴 보존·실패 원자성을 시험합니다. 한국어 UI는 실제 렌더 버퍼와 승인 선택 값을 대조합니다. 로그는 실제 파일·경쟁 프로세스로 새 파일 저장, 기존 파일 보존, 목적지 장애 후 재시도, 역압 및 비밀 필드 제외를 시험합니다. 실행 결과와 최종 바이너리 해시는 빌드 산출물의 영수증을 기준으로 보고합니다.
